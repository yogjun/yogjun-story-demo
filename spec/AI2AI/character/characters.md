# 主要角色

## Servant

1. **蓝染惣右介（Saber）**
   - 出处：死神
   - 状态：刚获得崩玉，离开尸魂界
   - 执念：寻找新的力量和生存方式
   - 特点：冷静、强大、内心复杂

2. **晓美焰（Archer）**
   - 出处：魔法少女小圆
   - 状态：小圆变成圆环之理
   - 执念：夺回小圆的人性
   - 特点：神秘、执着、拥有时间操纵能力

3. **蕾米莉亚·斯卡蕾特（Lancer）**
   - 出处：东方幻想乡
   - 状态：血雾异变
   - 执念：白天也能快乐玩耍
   - 特点：吸血鬼、强大、喜欢夜晚

4. **刹那F清英（Rider）**
   - 出处：机动战士高达00
   - 状态：结束后
   - 执念：结束一切战争
   - 特点：和平主义者、拥有强大机动能力

5. **纳兹（Caster）**
   - 出处：妖精的尾巴
   - 状态：天狼岛封印
   - 执念：击败黑龙，守护好大家
   - 特点：热血、强大、拥有火焰能力

6. **宇智波斑（Assassin）**
   - 出处：火影忍者
   - 状态：与千手柱间决裂前
   - 执念：寻找别的忍界和平的方式
   - 特点：强大、冷静、拥有写轮眼能力

## Master

1. **间桐樱**
   - 身份：日本旅行者
   - 特点：知道部分未来信息
   - 执念：未来能帮到学长
   - 与蓝染惣右介契约

2. **孤儿天才魔术师幼女**
   - 身份：被选中的孤儿
   - 特点：粘着蕾米莉亚·斯卡蕾特
   - 与蕾米莉亚·斯卡蕾特契约

3. **徐家庶出子嗣**
   - 身份：魔都本地方士家族庶出子嗣
   - 特点：想证明自己能力比兄长强
   - 与刹那F清英契约

4. **张家天才方士**
   - 身份：路过的隔壁方士家族天才
   - 特点：喜欢大闹一场
   - 与纳兹契约

5. **在逃罪犯**
   - 身份：家人被杀后灭对方满门的罪犯
   - 特点：寻求家人复活
   - 与宇智波斑契约
